What you're downloading

The download is Coilbox — a launcher that handles the engine, the game files and the maps for you — pre-configured for SplinterFaction. Download, unpack, run. On Windows, unpack somewhere other than Program Files.

The game itself and the maps aren't in that first download. Coilbox fetches them from its first screen, which keeps the download small and means you never install an out-of-date version. After that it checks for new versions on launch and fetches only what's changed, so you never need to reinstall.
