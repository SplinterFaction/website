Your battle appears in the lobby. Nobody can connect to it. It isn't a bug.

The fix

Hosting directly from your own machine means other players connect to you, which means your router has to let them in. Forward TCP/UDP port 8254 to the local IP address of the computer that will host. That's the default; it can be changed on the Host a New Battle screen if 8254 is already in use on your network. Port forwarding is done in your router's admin interface, not in the game — search for your router model plus "port forwarding" if you haven't done it before.

The easier fix

Don't host. There are official SPADS autohosts — permanently-running servers that host battles for you. Join one, set up your game through its commands, play. No configuration, no network setup, no penalty, and it's what most players use anyway.

While we're here

If a multiplayer game desyncs or crashes, check first that everyone is on the same version — Coilbox handles this automatically, manual installs may not. If the versions match, please report it on GitHub with two attachments: your infolog.txt from your Recoil data directory, and the replay file for the match. Those two together are usually enough to find the cause. A report without them generally isn't actionable, however detailed the description.
