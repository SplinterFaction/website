You never need to reinstall SplinterFaction. Coilbox checks for a new version every time it launches and fetches only what changed.

What that means in practice

The initial download deliberately doesn't include the game or any maps — it keeps the package small and means you're never installing an out-of-date build. After that, staying current is automatic. It also means everyone in a multiplayer lobby is on the same version, which is the first thing to check if a game desyncs. Manual installs may not match; Coilbox installs do.

What a patch note here will cover

  • Balance changes, with the reasoning — numbers move, and if you're reading during a period of active tuning, assume everything is provisional.
  • New units, structures and abilities, cross-referenced to the unit reference pages on this site.
  • Interface changes to the Static GUI and default keybinds. (Your own rebinds always win; SF's defaults only fill gaps.)
  • Engine-level changes worth knowing about.

Bugs, crashes and desyncs go to the GitHub repository with your infolog.txt and the replay attached.
